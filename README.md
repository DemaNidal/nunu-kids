# NUNU KIDS — متجر ملابس المواليد

متجر إلكتروني بالعربي لملابس البيبي من الولادة لعمر سنة، مع بكجات تجهيز المولود.
الدفع عند الاستلام، والعملة شيكل (₪). فيه لوحة تحكم كاملة، والبيانات بقاعدة بيانات PostgreSQL.

## التشغيل أول مرة

1. لازم يكون PostgreSQL مثبّت وشغّال.
2. انسخي `.env.example` باسم `.env` وعبّي كلمة سر PostgreSQL، واسم وكلمة سر الأدمن.
   (ملف `.env` ما بينرفع على GitHub — خلّيه عندك بس)
3. من تيرمنال VS Code داخل مجلد المشروع:

```bash
npm install
```

```bash
npm run db:migrate
```

```bash
npm run db:seed
```

`db:migrate` بيعمل قاعدة البيانات والجداول، و`db:seed` بيعبّيها بالمنتجات والعروض والكوبونات الأولية وبيعمل حساب الأدمن.

## التشغيل كل يوم

```bash
npm start
```

- المتجر: http://localhost:5173
- لوحة التحكم: http://localhost:5173/admin/
- من الموبايل (نفس الواي فاي): العنوان اللي بيطبعه السيرفر

للتطوير: `npm run dev` بيعيد تشغيل السيرفر لحاله لما يتعدل كوده.

> ⚠️ لا تفتحي الصفحات بدبل كليك — لازم دايماً عن طريق السيرفر.

## أوامر مفيدة

| الأمر | شو بيعمل |
|---|---|
| `npm run db:studio` | بيفتح جداول قاعدة البيانات بالمتصفح (للتصفح والتعديل اليدوي) |
| `npm run db:migrate` | بعد أي تعديل على `prisma/schema.prisma` |
| `npm run admin:password` | تغيير كلمة سر الأدمن (من `ADMIN_PASSWORD` بملف `.env`) |
| `npm run db:backup` | نسخة احتياطية هلأ بمجلد `backups/` |
| `npm run db:restore` | بيعرض النسخ الموجودة. للاسترجاع: `npm run db:restore -- <اسم الملف> --yes` |

## النسخ الاحتياطي

- السيرفر بيعمل نسخة تلقائية كل يوم الساعة 3 الصبح (`BACKUP_HOUR` بـ `.env`)، وإذا كان الجهاز طافي بيعملها أول ما يشتغل.
- على الجهاز (`backups/`): آخر 14 نسخة + نسخة من كل أسبوع لـ 8 أسابيع. المجلد ما بينرفع على GitHub (فيه معلومات الزبائن).
- على Cloudflare R2 (إذا المفاتيح موجودة): كل نسخة بتنرفع **مشفّرة** (AES-256). بنخلي شهر كامل + نسخة أسبوعية لنص سنة. إذا ما كان في نت، بتنرفع لحالها لما يرجع.
- لوحة التحكم ← **النسخ الاحتياطية**: الحالة، "اعملي نسخة هلأ"، تنزيل، رفع ملف نسخة، و**استرجاع** (بكلمة السر).

### ربط Cloudflare R2 (مرة وحدة)

1. بلوحة Cloudflare ← **R2** ← **Create bucket** باسم `nunu-backups` (خليه خاص — مش public).
2. **Manage R2 API Tokens** ← **Create API token** ← صلاحية **Object Read & Write** لهاد الـ bucket بس.
3. انسخي **Account ID** و **Access Key ID** و **Secret Access Key** لملف `.env` (شوفي `.env.example`).
4. اعملي مفتاح تشفير وحطيه بـ `BACKUP_KEY`:
   `node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"`
   **احفظيه برا الجهاز** (مدير كلمات السر) — بدونه النسخ اللي على Cloudflare ما بتنفتح.
5. أعيدي تشغيل السيرفر، وبصفحة النسخ الاحتياطية اضغطي "اعملي نسخة هلأ".

### الاسترجاع

- من لوحة التحكم: جنب أي نسخة ← **استرجاع** ← كلمة السر. قبل ما يبدّل البيانات بيعمل نسخة `-beforerestore` من الوضع الحالي، فبتقدري ترجعي عنه بنفس الطريقة.
- جهاز جديد: ركّبي المشروع وقاعدة البيانات (`npm run db:deploy`) وحطي نفس `.env` (مع نفس `BACKUP_KEY`)، وبعدين استرجعي من قائمة Cloudflare، أو ارفعي ملف نسخة نزّلتيه قبل.
- من التيرمنال:
  - `npm run db:restore` ← النسخ على الجهاز، `npm run db:restore -- --cloud` ← النسخ على Cloudflare
  - `npm run db:restore -- <اسم النسخة> --yes` (زيدي `--cloud` إذا من Cloudflare)

## الصور

- لما ترفعي صورة منتج، المتصفح بيعمل منها 3 أحجام WebP (400 / 800 / 1600)، وكل صفحة بتاخد الحجم اللي بيلزمها.
- إذا `R2_IMAGES_BUCKET` و `R2_IMAGES_URL` موجودين بـ `.env`، الصور بتنرفع على Cloudflare R2. وإلا بتنحفظ بـ `public/uploads`.
- لما تحذفي منتج أو تشيلي صورة منه، بتختفي من المتجر فوراً، والملف نفسه بينحذف من التخزين بعد 30 يوم (عشان لو استرجعتي نسخة احتياطية من قبل، الصور تضل). الصور اللي بطلبات آخر 90 يوم بتضل.
- `R2_IMAGES_URL` هلأ رابط `r2.dev` المؤقت. بعد شراء الدومين بنربط `img.nunukids.com` وبنغيّر هالسطر بس، والصور ما بدها تنرفع من جديد.

## السرعة واختبار الضغط

- بيانات المتجر (`/api/store`) محفوظة بالذاكرة وبتتجدد كل 15 ثانية، وفوراً بعد أي تعديل أو طلب.
- الصور بتتخزن بالمتصفح (الصور المرفوعة سنة كاملة، وصور الموقع يوم).
- `npm run loadtest -- <الرابط> <عدد الزوار> <الثواني>`: اختبار ضغط بطلبات قراءة بس. مثلاً `npm run loadtest -- http://localhost:5173 300 20`

## الأمان باختصار

- الأسعار والخصومات والتوصيل بتنحسب من جديد بالسيرفر — ما بنثق بأرقام المتصفح.
- المخزون بينقص بنفس لحظة الطلب (ما بتنباع قطعة مرتين)، والإلغاء بيرجّعها.
- كلمة سر الأدمن مشفّرة، والجلسة بكوكي `HttpOnly`، وفي حد لمحاولات الدخول.
- قائمة الكوبونات مش ظاهرة للزبائن — الكود بيتفحص بالسيرفر.
