# NUNU KIDS — متجر ملابس المواليد

متجر إلكتروني بالعربي لملابس البيبي من الولادة لعمر سنة، مع بكجات تجهيز المولود.
الدفع عند الاستلام، والعملة شيكل (₪).

## تشغيل الموقع على جهازك

من داخل مجلد المشروع:

```bash
python -m http.server 5173 --directory public
```

وبعدين افتحي: http://localhost:5173

## ترتيب الملفات

```
public/
├── index.html          الصفحة الرئيسية
├── product.html        صفحة المنتج / البكج  (product.html?id=1)
├── checkout.html       إتمام الطلب
├── assets/logo.png     الشعار
├── css/
│   ├── style.css       التصميم العام (الألوان، الهيدر، الفوتر، الكروت، السلة)
│   ├── product.css     تصميم صفحة المنتج
│   └── checkout.css    تصميم صفحة إتمام الطلب
└── js/
    ├── data.js         بيانات المتجر: المنتجات، المخزون، مناطق التوصيل، والعروض + محرّك العروض
    ├── recs.js         الاقتراحات الذكية (بتتعلم من تصرفات الزبونة)
    ├── layout-markup.js  HTML الهيدر والفوتر والسلة (مشترك لكل الصفحات)
    ├── layout.js       منطق السلة وشريط الإعلانات وبطاقة المنتج
    ├── home.js         الصفحة الرئيسية
    ├── product.js      صفحة المنتج
    └── checkout.js     إتمام الطلب
```

## العروض

العروض اختيارية وبتتحكم فيها من `OFFERS` بملف `js/data.js` (ولاحقاً من لوحة الأدمن).
إذا ما في عرض فعّال، كل عناصر العروض بتختفي لحالها.
للمعاينة بدون عروض: `index.html?offers=off`
