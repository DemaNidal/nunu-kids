# NUNU KIDS — متجر ملابس المواليد

متجر إلكتروني بالعربي لملابس البيبي من الولادة لعمر سنة، مع بكجات تجهيز المولود.
الدفع عند الاستلام، والعملة شيكل (₪).

## تشغيل الموقع على جهازك

من تيرمنال VS Code (داخل مجلد المشروع):

```bash
npm start
```

وبعدين افتحي: http://localhost:5173

> ⚠️ لا تفتحي `index.html` بدبل كليك — الصفحة رح تطلع فاضية (بس عناوين)،
> لأن المتصفح بيمنع ملفات الـ JavaScript لما الصفحة تنفتح كملف. لازم دايماً عن طريق السيرفر.

للتطوير: `npm run dev` بيعيد تشغيل السيرفر لحاله لما يتعدل `server.js`.

## ترتيب الملفات

```
public/
├── index.html · product.html · checkout.html   الصفحات (هيكل بس، المحتوى بيتعبى من JS)
├── assets/logo.png
│
├── css/
│   ├── base.css         الألوان، الخطوط، الأزرار، الشارات
│   ├── layout.css       الهيدر، الفوتر، السلة الجانبية
│   ├── components.css   كرت المنتج، السعر، العداد، الكمية، الاقتراحات
│   └── pages/           تصميم خاص بكل صفحة (home / product / checkout)
│
└── js/                  (ES Modules)
    ├── config.js        إعدادات المتجر: التوصيل، الواتساب، الأقسام، المقاسات
    ├── utils.js         أدوات صغيرة: $، money، esc، img، storage
    │
    ├── data/            البيانات (لاحقاً من السيرفر)
    │   ├── products.js  المنتجات والبكجات والمخزون
    │   ├── offers.js    العروض
    │   └── content.js   صور البانر، الأعمار، الآراء، دليل المقاسات
    │
    ├── store/           المنطق (بدون أي HTML)
    │   ├── catalog.js   الوصول للمنتجات والمخزون
    │   ├── pricing.js   محرّك العروض وحساب الأسعار
    │   ├── cart.js      السلة (والصفحات بتسمع لتغييراتها)
    │   ├── orders.js    حفظ الطلب (لاحقاً بيبعت للسيرفر)
    │   ├── behavior.js  تتبع تصرفات الزبونة
    │   └── recommend.js الاقتراحات الذكية
    │
    ├── ui/              قطع الواجهة المشتركة
    │   ├── icons.js     كل الأيقونات
    │   ├── components.js  كرت المنتج، السعر، العداد، الكمية، toast
    │   ├── header.js · footer.js · cart-drawer.js
    │   └── layout.js    بيركّب الهيدر والفوتر والسلة بكل صفحة
    │
    └── pages/           كود كل صفحة لحالها
        ├── home.js
        ├── product.js
        └── checkout.js
```

**القاعدة:** `data` ← `store` ← `ui` ← `pages`. كل طبقة بتستخدم اللي قبلها بس.

## العروض

العروض اختيارية وبتتحكم فيها من `js/data/offers.js` (ولاحقاً من لوحة الأدمن).
إذا ما في عرض فعّال، كل عناصر العروض بتختفي لحالها.
للمعاينة بدون عروض: `index.html?offers=off`
